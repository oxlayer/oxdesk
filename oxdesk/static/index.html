Switching machines

Switch at the screen edge Push the mouse past the edge of the screen toward a machine placed next to this one in Layout, and the keyboard and mouse go there.
Keyboard shortcut Hold both keys of the pair together to send the keyboard and mouse to the next machine. The same pair brings them back.
Devices follow the leader When the leader changes machine, the other devices go with it. Pick the mouse if you switch by the edge, the keyboard if you use its Easy-Switch button.
